# 三角洲行动 TTK 计算器

一个面向《三角洲行动》烽火地带的静态前端 TTK 计算工具，用于对比不同武器、枪管、枪口、弹药和命中概率模型下的击杀时间表现。

项目地址：[https://github.com/PingWang98/-ttk-calculator](https://github.com/PingWang98/-ttk-calculator)

## 主要功能

- 按武器、配件、子弹和距离计算 TTK 排行榜。
- 支持肉伤、甲伤、护甲等级、头盔、手部防护、命中率等目标参数。
- 支持全局枪管策略、一键排除部分武器类型、保留自定义武器配置。
- 支持命中部位概率模型，用户可以手动输入非负权重，并通过“归一化”按钮等比缩放到总和 1。
- 支持马尔可夫命中模型，用于模拟连续命中部位变化。
- 支持 TTK 距离曲线、武器详细击杀过程、手动命中序列结算。
- 内置 S10 更新日志和枪械射程 / 初速计算机制说明。

## 当前数据范围

当前版本以 S10 靶场可确认数据为主，包含：

- M7、AS Val、AK-12 的 S10 数值调整。
- ASh-12 HVK 双发套件。
- RM277、SVCH 等新增武器。
- 6.8×51mm 弹药组与 9×19mm CT / .45 ACP CT 修脚弹药机制。
- SVCH 碳纤长枪管 + 镀铬爆发枪机机制，默认按常用装配处理。
- SR-25 瞬息短枪管三段衰减曲线。
- SMG-45 射程段修正。

未能稳定靶场测试或机制不明确的数据暂不进入计算，例如 9×39mm PAB 系列易伤机制。

## 射程与初速机制

普通枪管采用当前实测确认的通用射程公式：

```text
最终射程 = 基础射程 × (枪管射程倍率 + 枪口射程加成)
```

示例：

- SKS 第二段基础射程 90m，瞬息超长枪管 1.3，死寂 +0.24：`90 × (1.3 + 0.24) = 138.6`，游戏显示 139m。
- RM277 第一段基础射程 55m，鲸鲨枪管 1.3，断流消音器 +0.18：`55 × (1.3 + 0.18) = 81.4`，游戏显示 81m。

初速不从射程倍率反推。部分连狙和特殊枪管的射程加成与初速加成不一致，当前按独立数据处理。

## 使用方式

这是一个纯静态项目，不需要构建步骤。

最简单的方式是直接打开：

```text
index.html
```

也可以在项目目录启动一个本地静态服务：

```powershell
python -m http.server 8012
```

然后访问：

```text
http://127.0.0.1:8012/index.html
```

## 文件说明

- `index.html`：主页面入口。
- `index_optimized.html`：同内容的优化入口，当前与主页面保持同步。
- `bundle.js`：核心武器数据、配件数据、TTK 计算逻辑和交互逻辑。
- `styles_optimized.css`：主要样式文件。
- `assets/`：图标、图片和第三方前端资源。
- `formula.docx`：公式说明文档。

## 部位概率规则

部位概率输入框允许填入任意非负数值，方便先按权重录入，例如：

```text
头 10 / 胸 30 / 腹 19 / 手 23 / 脚 18
```

点击“归一化”后会等比缩放为总和 1 的概率。若总和不是 1，系统会拒绝生成 TTK 排行榜，避免使用未归一化数据参与计算。

## 数据原则

- 能靶场验证的数据优先。
- 不确定机制不进入正式计算。
- 普通枪管尽量使用统一倍率公式。
- SR-25、PSG-1 / SR9、Marlin 等特殊武器保留独立射程 / 初速数据。
- 新版本更新后，应优先核对旧枪算法和重点武器，再补新增内容。
