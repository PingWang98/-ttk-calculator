# DELTA LAB 本地界面预览

在项目目录运行：

```sh
node serve-local.cjs
```

打开 http://127.0.0.1:8765 。服务仅监听本机，不需要安装依赖。端口被占用时可运行 `node serve-local.cjs 8766`。

新界面由 `ui-lab.css`、`ui-lab.js` 和两个同步的 HTML 入口组成。原有计算引擎、S11 数据、装配配置和存储键保持兼容。

- 石墨黑与荧光绿视觉、雷达示意图、桌面侧栏和手机底栏。
- 当前交战条件摘要与真实模拟结果；配置变化后提示重新计算。
- 排行榜/距离曲线标签切换，支持键盘方向键。排行榜随武器数量横向扩展。
- 军械库名称/类型搜索；搜索仅影响显示，不改变模拟范围。原有排行筛选和剔除功能仍影响军械库可见项。
- 保留克隆、配件与弹药、命中分布、马尔可夫矩阵、逐发伤害和更新说明。
- 支持减少动态效果的系统偏好，不依赖外部图片或新增 JS 库。

验证：15 项计算回归测试通过；浏览器实测排行榜、距离图、伤害详情、93R 套件互斥、搜索和空状态、标签键盘操作、矩阵开关及更新日志。手机 390 px 视口无页面横向溢出。
